* 更新日時: 2026-11-19T12:08:00+09:00

## 背景・目的

既存の Bob 日本語FAQサイトに対して、視覚的なブランディング（Bob ロゴの配置、公式リンクへの導線、Bob ロゴ画像に合わせたカラーリング）を施し、さらに利便性と閲覧快適性を向上させるためのダークテーマ切り替え機能を追加する。

## 現在の挙動

* ヘッダーにはテキストのみが表示されており、ロゴ画像や外部リンクが存在しない。
* サイト全体のテーマカラーは単一のライトテーマ（ブルー: `#0f62fe`、背景: 白 / `#f4f4f4`）となっている。
* ダークテーマの表示や切り替え機能は備わっていない。

## 期待する挙動

* サイトヘッダー左上に Bob のロゴ画像（`bob.svg`）が表示され、クリックすると IBM Bob の公式サイト（`https://www.ibm.com/products/bob`）が新規タブで開く。
* サイト全体のテーマカラーが Bob ロゴの配色（ブルー `#0f62fe` 〜 パープル `#a56eff` へのグラデーションおよびアクセント）に刷新される。
* ヘッダー右上にテーマ切り替えボタン（☀️/🌙 等）が配置され、クリックするとライトテーマとダークテーマが即時切り替わる。
* 選択されたテーマ設定は `localStorage` に保存され、ページ再読み込み時にも維持される。未設定時は OS の `prefers-color-scheme` を反映する。

## 対象範囲・対象外

### 対象範囲

* `site/bob.svg` の配置（ルートにある `bob.svg` のコピー）
* `site/index.html`（ヘッダー構造の改修: ロゴリンク・テーマ切り替えボタンの追加）
* `site/style.css`（Bob カラーパレット定義、ライト/ダーク用 CSS 変数、グラデーション装飾、ダークテーマスタイル、ヘッダーのレスポンシブレイアウト）
* `site/app.js`（テーマ切り替えイベントハンドラ、`localStorage` 連携、OS カラー設定の検知・適用ロジック）

### 対象外

* `qa.md` の改変
* FAQ 検索・カテゴリ絞り込み・アコーディオン開閉ロジックの破壊的改変
* 外部ライブラリ（React, Vue, Tailwind, Bootstrap 等）の導入
* バックエンドやビルドシステムの導入

## 利用者・影響システム

* 利用者: FAQ サイトを閲覧するすべてのユーザー
* 影響システム: なし（静的フロントエンド単体で完結）

## 主な仕様

1. **Bob ロゴおよびリンク**:
   - ヘッダー内の左側に `site/bob.svg` を表示（高さ約 40px〜48px）。
   - 画像全体を `<a href="https://www.ibm.com/products/bob" target="_blank" rel="noopener noreferrer">` でラップし、`aria-label="IBM Bob 公式サイト（新しいタブで開く）"` を設定。
2. **テーマカラーの刷新とヘッダーグラデーション**:
   - Bob ロゴの特徴であるブルー（`#0f62fe`）とパープル（`#a56eff`）を採用。
   - ヘッダー全体の背景に Bob のグラデーション（`linear-gradient(135deg, #0f62fe 0%, #a56eff 100%)` 等）を適用し、ヘッダー内のタイトル・説明テキストを白系（`#ffffff` / 半透明白）で表示する。
   - カテゴリ見出しの下線、アクティブタブ等にグラデーションまたはアクセントパープル/ブルーを適用。
3. **ダークテーマ機能**:
   - `html` 要素に `data-theme="dark"` または `data-theme="light"` 属性を付与してテーマを制御。
   - 配色（ダーク時）:
     - 背景色: `#161616`（深めのダークグレー）
     - サブ背景・カード色: `#262626`
     - 本文テキスト色: `#f4f4f4`
     - 補助テキスト色: `#a8a8a8`
     - ボーダー色: `#393939`
     - アクセント色: `#4589ff` / `#be95ff`（ダーク背景に適した高コントラストなブルー/パープル）
   - トグルボタン:
     - ヘッダー右上（タイトル右側）に配置。
     - 現在の状態（ダーク/ライト）に応じたアイコンまたはテキストを表示。
     - キーボード操作可能（`<button>` 要素、フォーカスリング表示、`aria-label` 対応）。
4. **テーマの永続化**:
   - `localStorage.getItem('bob-faq-theme')` で前回の選択を取得。
   - 保存値がない場合は `window.matchMedia('(prefers-color-scheme: dark)')` を判定。
   - 変更時に `localStorage.setItem('bob-faq-theme', theme)` に保存。

## 制約・非機能要件

* バニラ HTML/CSS/JavaScript のみで動作し、`file://` プロトコルでもローカルで動作可能であること。
* アクセシビリティ（WCAG 2.1 AA レベルのコントラスト比確保、フォーカス可視化、スクリーンリーダー対応）。
* レスポンシブ対応（モバイル画面幅 320px からデスクトップまでレイアウト崩れがないこと）。

### 操作・画面遷移

* **ロゴクリック**: `https://www.ibm.com/products/bob` が新しいタブで開く。
* **テーマ切り替えボタンクリック / Enter / Space**: ライトテーマ ⇔ ダークテーマが切り替わる。
* 既存の検索入力、カテゴリ切り替え、アコーディオン開閉の動作はすべてそのまま維持される。

### 表示状態

* **ライトテーマ（初期/明示時）**: 白系背景、濃色テキスト、Bob ブルー/パープルのアクセント。
* **ダークテーマ（明示時/OS ダーク時）**: ダークグレー系背景、明色テキスト、ダーク用 Bob アクセント。
* **レスポンシブ表示**:
  - モバイル画面（幅 480px 以下）: ヘッダー内のロゴ、タイトル、テーマ切り替えボタンが縦またはコンパクトに並び、横スクロールが発生しない。

### 入力・バリデーション

* テーマ切り替えはトグル操作（クリック）のみ。バリデーションなし。

### デザイン要件

* **グラデーション**: `linear-gradient(135deg, #0f62fe 0%, #a56eff 100%)`
* **アクセントカラー**: ライト時は `#0f62fe` / `#8a3ffc`、ダーク時は `#4589ff` / `#be95ff`
* **コントラスト**: 背景色と本文色、ボタン色のコントラスト比 4.5:1 以上を確保。

### 参考資料

* `bob.svg`（カラー・ロゴ原本）
* `site/style.css`（既存 CSS 設計）

## 完了条件

1. `site/bob.svg` が配置され、ヘッダー左上に Bob ロゴ画像が表示されていること。
2. Bob ロゴをクリックすると `https://www.ibm.com/products/bob` に新規タブで遷移すること。
3. ヘッダー背景がグラデーションで表示され、テキストが白系色でコントラスト高く表示されること。またサイトのアクセントカラーに Bob のブルーおよびパープルが適用されていること。
4. テーマ切り替えボタンにより、ライトテーマとダークテーマがスムーズに切り替わること。
5. テーマ設定が `localStorage` に保持され、リロード後も選択テーマが復元されること。
6. 画面幅 320px 〜 1200px の範囲でレイアウト崩れや横スクロールが発生しないこと。
7. 既存の検索、カテゴリタブ、アコーディオン開閉機能が問題なく動作し、コンソールエラーがないこと。

## 確認方法

1. ブラウザで `site/index.html` を開き、以下の項目を目視および操作確認する:
   - ロゴ画像表示およびリンク遷移
   - テーマカラー（グラデーション等）の表示
   - テーマ切り替えボタンのクリック動作（ライト ⇔ ダーク）
   - ページリロード時のテーマ状態保持
   - 検索・カテゴリタブ・アコーディオンの動作
   - 画面幅を狭めた際のレスポンシブ表示
2. ブラウザの開発者ツールでコンソールエラーがないことを確認する。
3. `git status` / `git diff` で意図したファイルのみが変更されていることを確認する。

## リスク・懸念点

* ローカル `file://` プロトコルにおける `localStorage` の挙動（一部の厳格なブラウザ設定でブロックされる可能性）。エラーハンドリング（try-catch）を入れてフォールバックできるように実装する。
