## 背景・目的

`qa.md` に英語で記載されているBobのFAQ（4カテゴリ・17問）を日本語化し、バックエンドなしで閲覧できる静的FAQサイトとして提供する。ブラウザで `index.html` を開くだけで、FAQの閲覧・検索・カテゴリ絞り込みができる状態を目的とする。

## 現在の挙動

* FAQサイトに関するコードは存在しない。

## 期待する挙動

* キーワード検索とカテゴリ絞り込みにより、質問を探せる。
* 該当する質問がない場合は、0件の空状態が表示される。

## 主な仕様

### FAQデータ

* カテゴリは `qa.md` の見出し構成に従い、次の4つとする。
  1. 一般（General）: 5問
  2. 使い方（Usage）: 8問
  3. 高度な機能（Advanced Features）: 2問
  4. トラブルシューティング（Troubleshooting）: 2問
* 質問の順序は `qa.md` の順序を維持する。
* 回答は、段落、箇条書き、太字、インラインコードをHTMLで再現する。
* 固有名詞（Bob、MCP、VS Code、API key など）とコード片（`@/src/file.ts`、`@problems`、`.bob/rules/`、`/` など）は原文のまま残し、説明文を日本語化する。
* データは `faq-data.js` にJavaScriptの配列として保持し、`script.js` から参照する（`fetch` は使わない）。

### 表示・操作

* 質問をクリックすると回答が開閉する。初期状態は全て閉じている。
* 検索ボックスにキーワードを入力すると、質問文と回答文の部分一致（大文字小文字を区別しない）で、リアルタイムに絞り込む。
* カテゴリ絞り込みは「すべて」＋4カテゴリから選択する。検索とカテゴリ絞り込みは同時に適用される（AND条件）。
* 絞り込み結果に1件も該当しないカテゴリ見出しは表示しない。
* 全体で0件の場合は、空状態メッセージを表示する。

## 制約・非機能要件

* 素のHTML/CSS/JavaScriptのみで実装する。
* `file://` で `index.html` を直接開いて動作する（`<script>` による読み込みを用い、ES Modulesや `fetch` は使わない）。
* 回答の描画時に、ユーザー入力（検索語）をHTMLとして解釈しない（`textContent` 等を用いる）。FAQデータ中のHTMLは自前の固定データとして扱う。
* 対応ブラウザは、PC向けの最新の主要ブラウザ（Chrome / Edge / Safari / Firefox）とする。
* アクセシビリティとして、質問ボタンはキーボード操作（Tab、Enter、Space）で開閉でき、`aria-expanded` を設定する。

## UI・画面仕様

### 対象画面

FAQトップの1画面（単一ページ）のみ。

### 画面構成・表示項目

上から順に次の構成とする。

```text
+--------------------------------------------------+
| ヘッダー: よくある質問（FAQ）                    |
|           Bobに関するよくある質問と回答          |
+--------------------------------------------------+
| [ 検索ボックス: 質問や回答を検索...            ] |
| [すべて][一般][使い方][高度な機能][トラブル…]    |
+--------------------------------------------------+
| ■ 一般                                          |
|   ▶ Bobとは何ですか？                           |
|   ▶ Bobはどのように動作しますか？               |
|   ...                                            |
| ■ 使い方                                        |
|   ▶ 新しいタスクを開始するには？                |
|   ...                                            |
+--------------------------------------------------+
| （0件の場合）該当する質問が見つかりませんでした  |
+--------------------------------------------------+
```

* ヘッダー: タイトル「よくある質問（FAQ）」と、サブタイトル
* 検索ボックス: プレースホルダー付きのテキスト入力
* カテゴリ絞り込み: 「すべて」「一般」「使い方」「高度な機能」「トラブルシューティング」のボタン。選択中のボタンは強調表示する。
* FAQ一覧: カテゴリ見出しと、その配下の質問アコーディオン
* 本文は中央寄せの単一カラムとする。

### 操作・画面遷移

* 質問ボタンのクリック/キー操作で、回答の開閉を切り替える。
* 検索ボックスの入力で、一覧を即時に更新する。
* カテゴリボタンのクリックで、表示カテゴリを切り替える。
* 画面遷移はない。

### 表示状態

* 初期表示: 全カテゴリ・全17問を表示し、回答は閉じた状態とする。カテゴリ「すべて」を選択状態とする。
* 絞り込み後: 条件に合致する質問のみを表示する。
* 空状態: 「該当する質問が見つかりませんでした。キーワードやカテゴリを変更してください。」を表示する。
* 読み込み中・エラー: データはJSファイルとして同梱するため、該当なし。

### 入力・バリデーション

* 検索ボックスは自由入力とし、文字数制限や形式チェックは設けない。
* 前後の空白は無視する。
* 空の検索語は「絞り込みなし」として扱う。

### デザイン要件

* 任意のシンプルなデザイン（白基調、アクセントカラー1色、読みやすいフォント）とする。
* 日本語が読みやすいフォント指定とする（システムフォント）。
* PCのみ対応のため、レスポンシブ対応は行わない。
* キーボードフォーカスが視認できること。

* ブラウザで `faq-site/index.html` を開き、次を手動確認する。
  * 初期表示で17問が表示され、回答が閉じている。
  * 各質問の開閉（マウスとキーボード）。
  * 検索例: 「MCP」「コマンド」「undo」「zzzz」（0件）。
  * カテゴリ絞り込みと検索の併用。
  * 箇条書き・太字・インラインコードの表示。
* `faq-data.js` の質問数（17問）とカテゴリ別件数を、スクリプトまたは目視で `qa.md` と照合する。
* ブラウザの開発者コンソールにエラーが出ないことを確認する。
