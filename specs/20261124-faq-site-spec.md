# 仕様書: Bob 日本語FAQサイト

## 基本情報

* 種別: 新規実装
* 作成日時: 2026-11-24T14:51:51+09:00
* 更新日時: 2026-11-24T14:53:29+09:00
* 作成者: Bob
* ステータス: Approved

## 背景・目的

`qa.md`にBobに関するFAQ(英語)がある。これを日本語に翻訳し、バックエンドなしで閲覧できる日本語FAQサイトとして公開できる形にする。

## 現在の挙動

リポジトリにはFAQ原文の`qa.md`があるのみで、サイトやフロントエンドのコードは存在しない。

## 期待する挙動

`index.html`をブラウザで開くだけで、日本語のFAQを閲覧・検索・カテゴリ絞り込みできる。

## 対象範囲・対象外

### 対象範囲

* 静的サイトの新規作成(HTML / CSS / 素のJavaScript)
* `qa.md`のFAQ全件(4カテゴリ・17問)の日本語化と掲載
* キーワード検索、カテゴリ絞り込み、アコーディオン表示

### 対象外

* バックエンド、ビルド環境、フレームワークの利用
* `qa.md`自体の変更
* 多言語切替
* FAQの追加・編集用の管理画面

## 利用者・影響システム

* 利用者: FAQの閲覧者(Bobの利用者)
* 影響システム: なし(新規ファイルの追加のみ)

## 主な仕様

* FAQデータは日本語に翻訳し、`faq-data.js`にカテゴリごとの配列として保持する。
* カテゴリは「一般」「使い方」「高度な機能」「トラブルシューティング」の4つ(`qa.md`の見出しに対応)。
  * 一般: 5問 / 使い方: 8問 / 高度な機能: 2問 / トラブルシューティング: 2問(計17問)
* 回答中の`inline code`、箇条書き、太字は表示に反映する。コード表記(`@/src/file.ts`、`Ctrl/Cmd + Z`等)は原文のまま残す。
* 検索は質問と回答のテキストを対象に、入力に応じてリアルタイムで絞り込む(大文字小文字は区別しない)。
* カテゴリ絞り込みと検索は併用できる(AND条件)。
* 件数表示は、現在表示中のFAQ件数を示す。
* FAQ内容の埋め込みはDOM生成時にエスケープし、XSSを避ける(`textContent`ベースで組み立てる)。

> 注: 現状理解では「計22問」としたが、`qa.md`を確認した結果は17問(一般5、使い方8、高度な機能2、トラブルシューティング2)であった。この仕様書では17問に訂正している。

## 制約・非機能要件

* HTML、CSS、素のJavaScriptのみ。ビルド不要、外部通信なし(CDN、外部フォント等を使わない)。
* ファイル構成: リポジトリ直下に`index.html`、`style.css`、`script.js`、`faq-data.js`。
* アクセシビリティ: 質問は`button`要素、`aria-expanded` / `aria-controls`を設定。キーボードで操作可能、フォーカス表示あり。
* 対応ブラウザ: PC・スマートフォンのモダンブラウザ。
* `<html lang="ja">`を設定する。

## UI・画面仕様

### 対象画面

FAQトップの1ページのみ。

### 画面構成・表示項目

上から順に以下を配置する。

1. ヘッダー: サイトタイトル「Bob よくある質問」、補足文(1行)
2. 検索ボックス: プレースホルダー「キーワードで検索」
3. カテゴリ絞り込みボタン: 「すべて」「一般」「使い方」「高度な機能」「トラブルシューティング」
4. 件数表示: 「N 件のFAQ」
5. FAQ一覧: カテゴリ見出しの下に、アコーディオン形式のQ&Aを並べる
6. フッター: 簡易なコピー表記(任意の最小限)

### 操作・画面遷移

* 質問をクリック(またはEnter / Space)で回答を開閉する。複数同時に開ける。
* 検索入力で一覧を即時絞り込む。
* カテゴリボタンの選択で一覧を絞り込む(選択中のボタンは強調表示)。
* ページ遷移はない。

### 表示状態

* 初期表示: カテゴリ「すべて」、全件が折りたたまれた状態。
* 該当なし: 「該当するFAQがありません」を表示し、件数は0件とする。
* 読み込み中・エラー: ローカルデータのため設けない。
* 検索キーワードに一致した場合、質問・回答内の一致箇所の強調表示は行わない(スコープ外)。

### 入力・バリデーション

* 検索は自由入力。前後の空白は無視する。
* 空にすると全件表示に戻る。

### デザイン要件

* 既存デザインの指定はないため、シンプルで読みやすいデザインとする。
* レスポンシブ対応(PC幅、スマートフォン幅 約375px)。
* 十分な文字コントラスト、フォーカスリングの表示。
* 日本語に適したフォント指定(システムフォントのフォールバック)。

### 参考資料

なし。

* ブラウザの開発者ツールで画面幅を切り替えて確認する。
* キーボードのみで操作できることを確認する。
