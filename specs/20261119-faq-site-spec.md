# 仕様書: Bob 日本語FAQサイト

## 基本情報

* 種別: 新規実装
* 作成日時: 2026-11-19T11:43:53+09:00
* 更新日時: 2026-11-19T11:45:35+09:00
* 作成者: Bob
* ステータス: Approved

## 背景・目的

`qa.md` に英語で記載された Bob の FAQ（4カテゴリ・17問）を、日本語の利用者が閲覧しやすいよう、バックエンドなしの静的 FAQ サイトとして提供する。

## 現在の挙動

* FAQ は英語の Markdown（`qa.md`）のみで存在する。
* フロントエンドのコード、ビルド環境は存在しない。

## 期待する挙動

* `site/index.html` をブラウザで開くだけで、日本語の FAQ が表示される。
* キーワード検索とカテゴリ絞り込みで目的の Q&A を探せる。
* 質問をクリックすると回答が開閉する（アコーディオン）。

## 対象範囲・対象外

### 対象範囲

* `site/` 配下に静的サイト（HTML / CSS / JavaScript）を新規作成する。
* `qa.md` の全 17 問の日本語訳を `site/faq-data.js` に埋め込む。

### 対象外

* `qa.md` の変更（原本として維持する）
* バックエンド、ビルドツール、フレームワーク、外部 CDN
* ダークモード、すべて開く/閉じるボタン、URL ハッシュ直リンク
* ロゴ画像の表示（`bob.svg` は使用しない）
* 自動テスト基盤の導入

## 利用者・影響システム

* 利用者: Bob の FAQ を参照する日本語話者
* 影響システム: なし（既存ファイルへの変更なし）

## 主な仕様

1. カテゴリは「一般」「使い方」「高度な機能」「トラブルシューティング」の 4 つ（`qa.md` の General / Usage / Advanced Features / Troubleshooting に対応）。全 17 問（一般 5、使い方 8、高度な機能 2、トラブルシューティング 2。`qa.md` の構成・順序に一致させる）。
2. 質問・回答の全文を日本語に翻訳する。製品名・技術用語・コード表記（Bob、MCP、`@/src/file.ts`、`@problems`、`.bob/rules/`、VS Code、Ctrl/Cmd + Z など）は原文のまま残す。
3. 回答内の段落、箇条書き、太字、インラインコードの表現を維持する。
4. FAQ データは JS ファイル（`faq-data.js`）にグローバル変数として定義し、`fetch` を使わない（`file://` で動作させるため）。
5. 検索:
   * 質問文と回答文の両方を対象とする。
   * 前後の空白は無視し、大文字小文字を区別しない。
   * 入力に応じてリアルタイムで絞り込む。
   * 空白区切りの複数キーワードは AND 条件とする。
6. カテゴリ絞り込み: 「すべて」＋ 4 カテゴリのタブ。検索との併用が可能。
7. 一覧はカテゴリ見出しごとにまとめて表示する。該当 Q&A が 0 件のカテゴリ見出しは表示しない。
8. 検索中は一致した語句をハイライトしない（対象外の簡素化）。

## 制約・非機能要件

* 素の HTML / CSS / JavaScript のみ。`file://` で直接開いて動作する。
* 外部通信、外部ライブラリ、Web フォントの外部読み込みを行わない。
* 回答 HTML の挿入は `faq-data.js` 内の固定データのみとし、ユーザー入力を HTML として挿入しない（XSS 防止）。
* アクセシビリティ:
  * アコーディオンは `button` 要素を使用し、`aria-expanded` / `aria-controls` を付与する。
  * カテゴリタブはキーボード操作可能で、選択状態を `aria-pressed` 等で示す。
  * 検索ボックスにラベルを付与する。
  * フォーカス表示を視認可能にする。
* 対応ブラウザ: 最新の Chrome / Edge / Safari / Firefox
* `lang="ja"` を指定する。

## UI・画面仕様

### 対象画面

FAQ 一覧画面（単一ページ `site/index.html`）

### 画面構成・表示項目

上から順に以下を配置する。

1. ヘッダー: テキストのみ。タイトル「Bob よくある質問」、サブテキスト「Bob に関するよくある質問と回答をまとめています。」
2. 検索ボックス: ラベル「キーワードで検索」、プレースホルダー「例: モード、MCP、承認」
3. カテゴリタブ: 「すべて」「一般」「使い方」「高度な機能」「トラブルシューティング」
4. 件数表示: 「N 件の質問が見つかりました」（`aria-live="polite"`）
5. Q&A 一覧: カテゴリ見出し＋アコーディオン形式の質問行（質問文、開閉インジケーター）。開くと回答を表示する。
6. フッター: 「FAQ は qa.md を日本語に翻訳したものです。」

```text
+----------------------------------------------+
| Bob よくある質問                              |
| Bob に関するよくある質問と回答をまとめています。 |
+----------------------------------------------+
| キーワードで検索                              |
| [ 例: モード、MCP、承認                    ]  |
|                                              |
| [すべて][一般][使い方][高度な機能][トラブル…]   |
|                                              |
| 17 件の質問が見つかりました                    |
|                                              |
| 一般                                          |
|  ▸ Bob とは何ですか？                          |
|  ▾ Bob はどのように動作しますか？               |
|      回答本文 …                               |
|  ▸ …                                         |
| 使い方                                        |
|  ▸ …                                         |
+----------------------------------------------+
| FAQ は qa.md を日本語に翻訳したものです。       |
+----------------------------------------------+
```

### 操作・画面遷移

* 質問行のクリック、Enter、Space で該当回答を開閉する。複数の回答を同時に開ける。
* 検索ボックスへの入力で即時に一覧を絞り込む。
* カテゴリタブのクリックまたはキーボード操作で表示カテゴリを切り替える。切り替え時、検索語は維持する。
* 画面遷移はない。

### 表示状態

* 初期表示: 検索語なし、「すべて」選択、全 17 問が閉じた状態。
* 絞り込み後: 条件に一致する Q&A のみ表示。開閉状態は条件変更で閉じた状態に戻してよい。
* 空状態（0 件）: 「該当する質問が見つかりませんでした。キーワードやカテゴリを変更してお試しください。」を表示し、一覧は非表示にする。
* 読み込み中・エラー状態: 静的データのため設けない。

### 入力・バリデーション

* 検索ボックス: 任意のテキスト。前後空白を除去し、空文字は「条件なし」として扱う。最大長の制限は設けない。
* バリデーションエラー表示は不要。

### デザイン要件

* IBM ブルー（#0f62fe）基調のライトテーマ。背景は白〜薄いグレー（#f4f4f4）、本文色は #262626。
* システムフォント（日本語対応のフォントスタック）を使用する。
* レスポンシブ: 幅 320px 以上で横スクロールなし。幅が狭い場合、カテゴリタブは折り返すか横スクロール可能にする。コンテンツ最大幅は約 800px で中央寄せ。
* 本文と背景のコントラストは WCAG AA を満たす。
* 余計なアニメーションは設けない（開閉は即時、もしくは軽微な遷移のみ）。

## 確認方法

* `site/index.html` をブラウザで開き、手動で以下を確認する。
  * 初期表示、全問の開閉
  * 検索（質問文・回答文の一致、複数語 AND、大文字小文字、前後空白）
  * カテゴリ絞り込みと検索の併用
  * 0 件時の空状態
  * キーボード操作（Tab、Enter、Space）
  * 幅 320px / 768px / 1280px 程度でのレイアウト
* `qa.md` の質問見出し数（`###`）と `faq-data.js` の件数を `grep` / `node` 等で照合する。
* `git status` で変更が `site/` と `specs/` のみであることを確認する。

## リスク・懸念点

* 翻訳は公式訳ではなく、表現の妥当性はレビューが必要。
* `qa.md` が更新された場合、`faq-data.js` は手動で更新する必要がある（二重管理）。
* 実ブラウザでの目視確認は実行環境に依存し、自動では行えない可能性がある。その場合は未確認事項として報告する。
