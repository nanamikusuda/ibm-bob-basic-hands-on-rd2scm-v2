# 仕様書: Bob FAQ サイト（日本語・静的サイト）

## 基本情報

* 種別: 新規実装
* 作成日時: 2026-11-19T21:11:07+09:00
* 更新日時: 2026-11-19T21:12:58+09:00
* 作成者: Bob
* ステータス: Approved

## 背景・目的

`qa.md` に英語で記載された Bob の FAQ（全17問、4カテゴリ）を日本語化し、バックエンドなしで閲覧できる日本語FAQサイトとして提供する。利用者が `index.html` を開くだけで、FAQの閲覧・検索・カテゴリ絞り込みができる状態にする。

## 現在の挙動

* リポジトリには FAQ 元データ（`qa.md`、英語）、ロゴ画像（`bob.svg`）、仕様書・計画書テンプレートのみが存在する。
* フロントエンドの実装は存在しない。

## 期待する挙動

* ブラウザで `faq/index.html` を開くと、日本語のFAQが表示される（`file://` での直接オープンで動作する）。
* 質問をクリックすると回答が開閉する。
* キーワード検索とカテゴリタブで FAQ を絞り込める。

## 対象範囲・対象外

### 対象範囲

* `faq/` ディレクトリ配下の静的サイト一式（HTML / CSS / JavaScript）の新規作成
* `qa.md` 全17問の日本語訳（`faq/faq-data.js` に埋め込み）
* ヘッダーでのロゴ（`bob.svg`）表示
* 仕様書・実装計画書の作成

### 対象外

* `qa.md` の変更
* バックエンド、ビルド環境、フレームワーク、外部ライブラリ・CDN の利用
* スマートフォン向けの本格的なレスポンシブ対応
* 多言語切り替え
* 日本語の表記ゆれ吸収（かな・カナ変換、全角半角正規化など）を伴う検索

## 利用者・影響システム

* 利用者: Bob の利用者（PC ブラウザで閲覧）
* 影響システム: なし（既存ファイルへの変更なし）

## 主な仕様

### FAQ データ

* カテゴリは以下の4つ。`qa.md` の順序を維持する。

| ID | 表示名 | 原文カテゴリ | 質問数 |
| -- | ------ | ------------ | ------ |
| general | 一般 | General | 5 |
| usage | 使い方 | Usage | 8 |
| advanced | 高度な機能 | Advanced Features | 2 |
| troubleshooting | トラブルシューティング | Troubleshooting | 2 |

* 質問数の合計は17問。`qa.md` の `###` 見出し数と一致させる（実装時に照合する）。
* 製品名・コマンド・パス（Bob、MCP、VS Code、`@/src/file.ts`、`@problems`、`.bob/rules/`、`/` コマンド等）は原文のまま保持する。
* 回答内のリスト、太字、インラインコードの書式を維持する。
* データは `faq/faq-data.js` に JavaScript オブジェクトとして埋め込む。

### 検索

* 入力のたびに即時絞り込む（質問文と回答テキストが対象）。
* 部分一致、大文字小文字を区別しない。
* 空文字の場合は絞り込みなし。
* カテゴリタブとの併用が可能（両条件の AND）。

### カテゴリタブ

* 「すべて」「一般」「使い方」「高度な機能」「トラブルシューティング」の5つ。
* 初期状態は「すべて」。

### 開閉

* 質問クリックで回答を開閉する。複数同時に開ける。
* 初期状態はすべて閉じる。

## 制約・非機能要件

* HTML / CSS / JavaScript のみ。外部ライブラリ・CDN・ネットワーク通信に依存しない。
* `fetch` を使わず、`file://` で動作する。
* `<html lang="ja">` を設定する。
* キーボード操作（Tab、Enter、Space）で質問の開閉ができる。
* 対応ブラウザ: 最新の Chrome、Edge、Safari、Firefox。
* 回答テキストは `innerHTML` ではなく安全な方法で描画する（データは自前の固定データだが、書式はDOM生成で表現する）。

## UI・画面仕様

### 対象画面

FAQ トップページ1枚（`faq/index.html`）。ページ遷移なし。

### 画面構成・表示項目

上から順に以下を配置する。

1. ヘッダー: `bob.svg` ロゴ、タイトル「よくある質問（FAQ）」、説明文
2. 検索ボックス（プレースホルダー: 「キーワードで検索」）
3. カテゴリタブ（5つ）
4. 件数表示（例: 「17件のFAQ」「3件が見つかりました」）
5. FAQ リスト: カテゴリ見出し + 質問（開閉式）

```text
+----------------------------------------------+
| [logo] よくある質問（FAQ）                   |
|        Bob に関するよくある質問と回答        |
+----------------------------------------------+
| [ キーワードで検索                         ] |
| [すべて][一般][使い方][高度な機能][トラブル…]|
| 17件のFAQ                                    |
|                                              |
| 一般                                         |
|  ▸ Bob とは何ですか？                        |
|  ▾ Bob はどのように動作しますか？            |
|      回答本文…                               |
| 使い方                                       |
|  ▸ 新しいタスクはどう始めますか？            |
+----------------------------------------------+
```

### 操作・画面遷移

* 質問クリック／Enter／Space: 回答の開閉
* 検索入力: 即時に一覧を更新
* タブクリック: 選択カテゴリのみ表示（選択中のタブを強調表示）
* 検索結果で該当カテゴリに質問がない場合は、そのカテゴリ見出しも非表示にする

### 表示状態

* 初期表示: 「すべて」選択、検索欄は空、全質問が閉じた状態
* 読み込み中: なし（データはJS埋め込み）
* 空状態: 該当なしの場合「該当するFAQが見つかりませんでした。キーワードやカテゴリを変更してください。」を表示
* エラー: なし

### 入力・バリデーション

* 検索欄は自由入力。前後の空白は無視する。入力文字数の上限は設けない。

### デザイン要件

* シンプルなライトテーマ（白背景、控えめなアクセントカラー）。
* 本文最大幅は約800pxで中央寄せ。
* 狭い画面幅でも、横スクロールやレイアウト崩れが発生しない（タブは折り返す）。最低限の対応であり、スマートフォン向け最適化は対象外。
* フォーカス時の視認できるアウトラインを維持する。
* 本文と背景のコントラストを十分に確保する。

## 確認方法

* ブラウザで `faq/index.html` を開き、手動で以下を確認する。
  * 全質問の表示と開閉
  * 検索（日本語・英語キーワード、0件ケース）
  * タブ切り替え、検索との併用
  * キーボード操作
  * ウィンドウ幅を狭めた表示
* `qa.md` の質問数・内容と `faq-data.js` を照合し、訳抜けがないことを確認する。
* `node` が利用可能な場合は、`faq-data.js` の質問数をスクリプトで検証する。

## リスク・懸念点

* 日本語訳の表現は暫定であり、ユーザーによるレビューが必要。
* 実ブラウザでの目視確認は、実行環境によっては自動化できない可能性がある。その場合は未実施として報告する。
* 日本語の表記ゆれ（ひらがな／カタカナ等）には対応しないため、検索で見つからない場合がある。
