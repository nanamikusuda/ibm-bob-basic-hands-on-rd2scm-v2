## 主な仕様

### ロゴリンク

* `<img>` を `<a href="https://www.ibm.com/products/bob" target="_blank" rel="noopener noreferrer">` で囲む。
* リンクには `aria-label="Bob の製品ページを新しいタブで開く"` を設定する。画像の `alt` は空文字（`alt=""`）とし、リンクのラベルで読み上げさせる。
* キーボードフォーカス時に視認できるアウトラインを表示する。

### テーマカラー（`bob.svg` の配色に基づく）

| 用途 | ライト | ダーク |
| ---- | ------ | ------ |
| 背景（`--bg`） | `#ffffff` | `#161616` |
| 面（`--surface`） | `#f4f4f4` | `#262626` |
| 境界線（`--border`） | `#e0e0e0` | `#393939` |
| 本文（`--text`） | `#262626` | `#f4f4f4` |
| 補足文（`--muted`） | `#525252` | `#c6c6c6` |
| アクセント（`--accent`、フォーカス枠など） | `#0f62fe` | `#78a9ff` |
| 選択中タブの背景の始点（`--accent-strong`） | `#0f62fe` | `#0f62fe` |
| 選択中タブの背景の終点（`--accent-tab-end`） | `#8a3ffc` | `#8a3ffc` |
| 補助色（`--accent-sub`） | `#a56eff` | `#a56eff` |

* 本文系の色（`#262626`、`#f4f4f4`、`#525252`、`#c6c6c6`）は `bob.svg` のダークグレー・ライトグレーに基づく。
* 紫（`--accent-sub`）は装飾（グラデーション、下線）のみに使い、文字色には使わない。
* 紫・ブルーのグラデーション（`linear-gradient(90deg, #0f62fe, #a56eff)`）を以下に適用する。
  * ページ最上部の全幅バー（高さ4px）
  * カテゴリ見出しの下線
* 選択中のタブは背景を `linear-gradient(90deg, var(--accent-strong), var(--accent-tab-end))`（`#0f62fe` → `#8a3ffc`）のグラデーションとし、文字色は `#ffffff`（両テーマ共通）。境界線は透明にする。未選択のタブは変更しない。
* 選択中タブの終点を `#a56eff` ではなく `#8a3ffc` にするのは、白文字のコントラスト（約5:1）を確保するため。
* ブラウザ標準部品（検索欄など）にもテーマを反映するため、`color-scheme` を設定する。

### ダークテーマの適用方式

* `<html>` 要素の `data-theme` 属性（`light` / `dark`）で切り替える。CSS 変数を `:root` と `:root[data-theme="dark"]` で定義する。
* 初期テーマの決定順序:
  1. `localStorage` のキー `faq-theme` に保存された値（`light` または `dark`）
  2. 保存値がない場合は `prefers-color-scheme: dark` が一致すれば `dark`、それ以外は `light`
* 初回描画前にテーマが決まるよう、`<head>` 内のインラインスクリプトで `data-theme` を設定する（ライトからダークへのちらつきを避ける）。
* ボタン押下でテーマをトグルし、`data-theme` を更新して `localStorage` に保存する。
* `localStorage` の読み書きが失敗（無効化・例外）しても、エラーで動作を止めない（保存せずに動作を続ける）。

### テーマ切り替えボタン

* 位置: ヘッダー右端（ロゴ、タイトルと同じ行）。
* 表示ラベル: 現在のテーマと逆のテーマ名を表示する。ライト時は「ダークテーマ」、ダーク時は「ライトテーマ」。
* `aria-label` は「ダークテーマに切り替え」「ライトテーマに切り替え」。現在のテーマに応じて更新する。
* `<button type="button">` とし、Tab で到達でき、Enter / Space で操作できる。

### ダーク時のロゴ表示

* `bob.svg` は輪郭線が `#262626` のため、暗い背景に溶ける可能性がある。ダーク時のみロゴ画像に背景色 `#f4f4f4` と `border-radius: 12px` を付ける。画像のサイズ（56×56px）と位置は変えない。

## 制約・非機能要件

* HTML / CSS / JavaScript のみ。外部ライブラリ・CDN に依存しない。`file://` で動作する。
* インラインスクリプトの追加は、テーマの初期適用のみに限定する。
* 本文と背景のコントラストは WCAG AA（通常テキスト 4.5:1）を満たす。選択中タブの白文字と、グラデーションの両端（`#0f62fe`、`#8a3ffc`）の組み合わせも同様に満たす。
* DOM 生成は既存方針に従い、`innerHTML` を使わない。
* 対応ブラウザ: 最新の Chrome、Edge、Safari、Firefox。

## リスク・懸念点

* ブラウザでの目視確認は、実行環境によっては自動化できない可能性がある。その場合は未実施として報告し、手動確認を依頼する。
* ダーク時のロゴ背景（`#f4f4f4`）の見え方は目視確認が必要。違和感がある場合は調整が必要になる。
* 一部ブラウザでは `file://` で `localStorage` が共有・制限される場合がある。その場合も動作は継続し、選択が保持されないだけとする。
* 紫 `#a56eff` は文字色に使うとコントラストが不足するため、装飾専用とする。
