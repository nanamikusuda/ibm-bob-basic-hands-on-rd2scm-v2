## 実装手順

1. `faq/faq-data.js` を作成する。
   * 形式: `const FAQ_DATA = { categories: [{ id, label, items: [{ question, answer }] }] }`
   * `answer` は書式を表現できるブロック配列とする。
     * `{ type: "p", text: "..." }`
     * `{ type: "ul", items: ["...", "..."] }`
     * インライン書式は `text` 内で太字やコードをセグメント配列（`[{ text, bold?, code? }]`）として表現する。
   * `qa.md` の順序で17問すべてを日本語訳する。製品名・コマンド・パスは原文のまま保持する。
2. `faq/index.html` を作成する。
   * `<html lang="ja">`、ヘッダー（`../bob.svg` のロゴ、タイトル、説明文）、検索 `<input type="search">`、タブ用 `<div role="tablist">`、件数表示、リスト用 `<main>`、空状態用 `<p hidden>` を配置する。
   * `faq-data.js` → `app.js` の順で `<script>` を読み込む。
3. `faq/styles.css` を作成する。
   * ライトテーマ、本文最大幅約800px の中央寄せ、フォーカスアウトライン、タブの折り返し。
   * `@media (max-width: 600px)` で余白とフォントを調整し、横スクロールを防ぐ。
4. `faq/app.js` を作成する。
   * 状態: `selectedCategory`（初期 `all`）、`query`（初期空）。
   * 描画: 状態に応じてカテゴリ見出し + `<details>/<summary>` の質問を DOM API（`createElement`、`textContent`）で生成する。`innerHTML` は使わない。
   * 絞り込み: 質問文と回答テキスト（ブロックを連結した文字列）に対し、前後の空白をトリムしたクエリを小文字化して部分一致（AND条件でカテゴリと併用）。
   * 該当0件のカテゴリ見出しは非表示。全体で0件なら空状態メッセージを表示。
   * 件数表示: クエリ・カテゴリ未指定は「N件のFAQ」、それ以外は「N件が見つかりました」。
   * タブ: `role="tab"` と `aria-selected` を切り替える。
5. 動作確認（検証計画参照）を行い、問題があれば修正する。

## GUI実装

* 対象コンポーネント: `index.html` 内のヘッダー、検索欄、タブ、件数表示、FAQリスト（`app.js` が動的生成）、空状態メッセージ
* スタイル: `styles.css`（外部CSS、CDN不使用）。白背景、控えめなアクセントカラー、フォーカスアウトライン維持
* 状態管理: `app.js` 内のモジュールスコープ変数（`selectedCategory`、`query`）。変更のたびに `render()` を再実行
* 画面遷移: なし（単一ページ）
* レスポンシブ対応: 最大幅約800px、タブの `flex-wrap`、`@media (max-width: 600px)` で余白調整のみ。スマートフォン最適化は対象外
