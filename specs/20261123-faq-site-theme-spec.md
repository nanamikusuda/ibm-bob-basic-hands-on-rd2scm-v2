## 背景・目的

既存のFAQサイト（[`20261123-faq-site-spec.md`](20261123-faq-site-spec.md)）に、Bobのブランディング（ロゴ、配色）を反映し、ライト/ダークの表示テーマを選べるようにする。

既存仕様書では「ライト/ダークテーマの切替」が対象外だったため、本改修で対象に加える。既存仕様書は変更しない。

## 現在の挙動

* ヘッダーはテキスト（タイトル、サブタイトル）のみで、ロゴはない。
* ヘッダー背景は `#0f62fe` の単色で、全体は白基調の1テーマのみ。
* 色は `style.css` に固定値で記述されている。

## 期待する挙動

* ヘッダー左上にBobのロゴが表示され、クリックすると `https://www.ibm.com/products/bob` が新しいタブで開く。
* ヘッダー背景がBobの帽子と同じ配色（`#0f62fe` → `#a56eff`）のグラデーションになる。
* ヘッダー右上のボタンで、ライト/ダークを切り替えられる。
* 初回表示はOS設定に従い、手動で選んだテーマは次回以降も保持される。

## 主な仕様

### 1. ロゴ画像

* ヘッダー左上に、`faq-site/bob.svg` を高さ48pxで表示する（`height: 48px; width: auto`）。
* `<a href="https://www.ibm.com/products/bob" target="_blank" rel="noopener noreferrer">` で画像を包む。
* `<img>` の `alt` は「Bob（IBM Bobの製品ページを新しいタブで開く）」とする。

### 2. テーマカラー（ライトテーマ）

* ヘッダー背景: `linear-gradient(90deg, #0f62fe, #a56eff)`。ヘッダーの文字色は白とする。
* ボタン、カテゴリ見出しの縦線、質問の「＋/−」、フォーカスリングなどのアクセントは `#0f62fe` を維持する。
* その他の色（背景 `#ffffff`、文字 `#1f2328` など）は現状を維持する。

### 3. ダークテーマ

* 色はCSSカスタムプロパティで管理する。`<html data-theme="light|dark">` の値で切り替える。
* ダークテーマの配色は、次を基準とする（実装時に視認性を確認し、必要なら調整する）。

| 用途 | ライト | ダーク |
| --- | --- | --- |
| ページ背景 | `#ffffff` | `#161616` |
| 本文文字 | `#1f2328` | `#f4f4f4` |
| 補助文字（空状態） | `#57606a` | `#a8a8a8` |
| 区切り線・入力枠 | `#e0e0e0` / `#c6c6c6` | `#393939` / `#525252` |
| 入力欄背景 | `#ffffff` | `#262626` |
| インラインコード背景 | `#f0f0f0` | `#262626` |
| アクセント（ボタン・線・記号） | `#0f62fe` | `#78a9ff`（暗背景で十分なコントラストを確保） |
| 選択中ボタン | 背景 `#0f62fe`・文字 白 | 背景 `#78a9ff`・文字 `#161616` |
| ヘッダー背景 | グラデーション（上記） | 同じグラデーション |

* テーマの決定順序:
  1. `localStorage`（キー `faq-theme`）に `light` / `dark` が保存されていれば、それを使う。
  2. なければ `prefers-color-scheme: dark` に従う。
  3. いずれも判定できなければ `light`。
* 切替ボタンをクリックすると、テーマが即時に切り替わり、選択値が `localStorage` に保存される。
* チラつき防止のため、`<head>` 内の小さなインラインスクリプトで `data-theme` を先に設定する。
* `localStorage` へのアクセスが失敗しても（例外が発生しても）、エラーにせずに動作を継続する。

## 制約・非機能要件

* 素のHTML/CSS/JavaScriptのみ。外部ライブラリ、CDN、外部フォントは使わない。
* `file://` で動作する。
* 切替ボタンは `<button type="button">` とし、キーボード（Tab、Enter、Space）で操作できる。現在の状態を `aria-pressed` で示す（ダーク時に `true`）。
* 既存の機能（検索、カテゴリ絞り込み、開閉）に影響を与えない。
* 対応ブラウザは既存仕様と同じ（PC向けの最新の主要ブラウザ）。

## UI・画面仕様

### 対象画面

FAQトップの1画面（ヘッダーの構成変更と、全体のテーマ対応）。

### 画面構成・表示項目

```text
+------------------------------------------------------------+
| [Bobロゴ]                                  [ ダーク表示 ]  |
|            よくある質問（FAQ）                              |
|            Bobに関するよくある質問と回答                    |
|  （背景: #0f62fe → #a56eff のグラデーション）               |
+------------------------------------------------------------+
| （以下は既存どおり: 検索ボックス、カテゴリ、FAQ一覧）       |
```

* ロゴ: ヘッダー左上、高さ48px、リンク付き
* タイトル/サブタイトル: 既存どおり中央寄せ
* テーマ切替ボタン: ヘッダー右上。ラベルは次のとおり（絵文字は使わない）。
  * ライト表示中: 「ダーク表示」
  * ダーク表示中: 「ライト表示」
* ロゴとボタンはヘッダー内で絶対配置（または同等の方法）とし、タイトルの中央寄せを崩さない。

### 操作・画面遷移

* ロゴのクリック: `https://www.ibm.com/products/bob` を新しいタブで開く。現在のFAQ画面は残る。
* 切替ボタンのクリック: テーマを即時に反転し、ラベル、`aria-pressed`、`localStorage` を更新する。
* 画面遷移（FAQ内）はない。

### 表示状態

* 初期表示: `localStorage` → OS設定 → ライト の順で決定したテーマで表示する。
* ライト/ダークの2状態。ヘッダー以外の領域（背景、文字、入力欄、ボタン、区切り線、コード、空状態メッセージ）がテーマに追従する。
* 読み込み中・エラー・空状態の表示内容は既存どおり（色のみテーマに追従）。

### 入力・バリデーション

* 変更なし（検索ボックスは既存どおり）。

### デザイン要件

* 配色はBobのロゴ色（`#0f62fe`、`#a56eff`、`#262626`）に準拠する。
* ダークテーマの文字とアクセントは、背景に対して十分なコントラストを確保する。
* ロゴの輪郭線は `#262626` のため、グラデーションのヘッダー上で視認できることを確認する。視認性に問題がある場合は、実装を止めて対応を相談する。
* キーボードフォーカスが、両テーマで視認できること。
* PCのみ対応（既存どおり）。

## リスク・懸念点

* ブラウザでの実機確認は、この環境で自動化できない場合がある。その場合は、構文チェックと差分確認を実施し、未実施の手動確認を明示する。
* ロゴの輪郭が暗色のため、グラデーションのヘッダー上での見え方に個人差が出る可能性がある。
* ダークテーマの配色値は基準値であり、実機確認で調整が必要になる可能性がある。
* `faq-site/bob.svg` はルートの `bob.svg` のコピーであり、元の画像が更新されても自動では同期されない。
