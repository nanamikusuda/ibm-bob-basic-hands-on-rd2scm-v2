## 実装手順

1. `faq-site/faq-data.js` を作成する。
   * `const FAQ_DATA = [{ id, title, items: [{ question, answer }] }, ...]` の形式とする。
   * カテゴリ4つ（一般5問 / 使い方8問 / 高度な機能2問 / トラブルシューティング2問）、合計17問。
   * `answer` はHTML文字列（`<p>`、`<ul><li>`、`<strong>`、`<code>`）とする。
2. `faq-site/index.html` を作成する。
   * `lang="ja"`、UTF-8、`<header>`、`<input type="search">`、カテゴリボタン用 `<nav>`、一覧用 `<main>`、空状態用要素（初期は非表示）を配置する。
   * `faq-data.js`、`script.js` を `defer` なしの末尾 `<script>` で順に読み込む。
3. `faq-site/style.css` を作成する。
   * 白基調、アクセント色1色、システムフォント（日本語対応）、中央寄せ単一カラム（最大幅 約800px）。
   * 選択中カテゴリボタンの強調、アコーディオンの開閉表示、`:focus-visible` のフォーカス表示、`code` のスタイル。
4. `faq-site/script.js` を作成する。
   * 状態: `selectedCategory`（初期 `all`）、`keyword`（初期 空）。
   * カテゴリボタンを `FAQ_DATA` から生成する（「すべて」＋各カテゴリ）。
   * `render()` で、状態に合致する質問のみ描画する。合致が0件のカテゴリ見出しは出さない。全体0件なら空状態を表示する。
   * 検索は、質問文と回答文（HTMLタグを除いたテキスト）に対する、大文字小文字を区別しない部分一致。入力は `trim()` する。
   * 質問は `<button aria-expanded aria-controls>` とし、クリック/Enter/Spaceで回答の開閉を切り替える（`button` の標準動作を利用）。
   * 検索語は `textContent` / 値比較のみに使用し、HTMLとして挿入しない。
5. データ照合と構文チェックを行う（Node.jsが利用可能な場合）。
   * `node --check` で `script.js` / `faq-data.js` の構文を確認する。
   * Nodeでデータを読み込み、カテゴリ数・質問数を `qa.md` の見出し数（`###` の数）と照合する。
6. 検証結果をまとめ、ユーザーに確認を依頼する。

## GUI実装

* 対象コンポーネント: ヘッダー、検索ボックス、カテゴリ絞り込みボタン群、カテゴリ見出し、質問アコーディオン、空状態メッセージ（いずれも `index.html` の要素と `script.js` による動的描画）
* スタイル: `style.css` に集約。CSSのみ（外部フォント・CDN不使用）
* 状態管理: `script.js` 内のモジュール内変数（`selectedCategory`、`keyword`）。変更のたびに `render()` を再実行する。各質問の開閉状態は `aria-expanded` とDOMの `hidden` 属性で管理する。再描画時は閉じた状態に戻る。
* 画面遷移: なし（単一ページ）
* レスポンシブ対応: 対象外（PCのみ）
